# 🧠 Stroke Prediction System

A web application that predicts the **risk of stroke** using Machine Learning, helping users assess their health status early and encouraging preventive care through personalized recommendations.

🔗 **Live Demo:** https://stroke-prediction-system-kaaqhnubn8rfdgdpvgzjkj.streamlit.app/

---

# 📖 About the Project

Stroke is one of the leading causes of death and long-term disability worldwide. Early prediction of stroke risk can help individuals take preventive actions and seek medical advice before serious complications occur.

This project uses Machine Learning to estimate a person's **stroke risk** based on medical and lifestyle information. The application provides an intuitive interface where users can enter their health details and instantly receive:

- 🧠 Stroke Risk Prediction
- 📊 Risk Percentage
- 💡 Personalized Health Recommendations

The model was trained using a stroke prediction dataset and enhanced with feature engineering and data preprocessing techniques to improve prediction performance.
